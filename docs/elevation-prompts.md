# Elevation image prompts (BOQFather)
Use these in Gemini / Midjourney / any image AI. Keep the **same camera, lighting and framing words** in every prompt so the whole set looks like one studio's work.
**Save each image as 1200 x 720 px (5:3), webp or jpg, named exactly as shown** and put it in `public/elevations/` (e.g. `30x40.webp`). It replaces the illustration on every page automatically.
Tip: generate 4 options per house, keep the best, and add a small line on the site: *Artist impression*.

> Photorealistic architectural visualization, eye-level three-quarter front view, golden-hour dusk with warm interior lights glowing, soft overcast-clear sky, wet driveway reflections, landscaped front garden, boundary wall with gate, 8K, ultra-detailed materials, realistic shadows. Indian residential setting. No text, no watermark, no logo, no people, no cars with readable number plates.
